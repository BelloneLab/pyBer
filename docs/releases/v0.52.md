# pyBer 0.52

This release expands PSTH and behavior summaries, simplifies baseline suggestions,
and gives the plots more space with compact controls and resizable shared panels.

## Downloads

- **Windows GUI:** download and run `pyBer-windows.exe`, a single executable with its runtime bundled inside.
- **Windows CLI:** download `pyBer-cli-windows.exe`; `--version` reports `pyBer 0.52.0`.
- **Checksums:** `SHA256SUMS.txt` lists SHA-256 hashes for both executables.

## Improvements

- Automatic pre-event baseline suggestions appear in a compact menu with whole-second windows and suitability scores. Applying a suggestion remains the user's choice. Scores describe signal/coverage suitability, not statistical confidence or proof of a biologically neutral baseline.
- Selectable behavior summaries include bout durations, inter-bout intervals and binned time courses, with median/IQR annotations and numerical exports.
- Selectable PSTH comparison panels and ten global signal metrics provide compact summaries. Global metrics preserve original processed units and account for missing samples and recording gaps.
- Heatmap and PSTH share one panel with aligned, synchronized time axes. The two behavior plots share another compact panel.
- Drag dividers to resize plots. View settings and panel proportions persist in app preferences and saved projects.
- Saved postprocessing projects restore embedded behavior, trajectory and clock data, including when the original behavior file is unavailable.
- Both workflows have compact single-line toolbars. Preprocessing keeps Sensor directly accessible and removes duplicate file-status metadata.
- Long preprocessing output titles wrap within their panel. Trace previews reserve enough room for time-axis labels.
- Windows file-drop guidance explains elevation restrictions and provides a normal-launch shortcut.

## Compatibility

Original recordings and metadata are not modified. Baseline selection remains an
analysis choice: short or contaminated windows can produce unstable normalization.
The FLMM path still requires an external R/fastFMM installation.
