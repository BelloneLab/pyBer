# pyBer 0.57

Recording groups with a group PSTH view, an editable results figure with vector
PDF/SVG export, line-by-line behavior pairing, and shorter settings panels.

## Downloads

- **Windows GUI:** `pyBer-windows.exe`, with its runtime bundled inside.
- **Windows CLI:** `pyBer-cli-windows.exe`; `--version` reports `pyBer 0.57.0`.
- **Checksums:** `SHA256SUMS.txt` contains SHA-256 hashes for both executables.

## Recording groups and group PSTH

- **Setup > Recordings and groups** creates labelled, colored groups (WT, Het,
  Saline...) and attributes recordings by clicking a group chip or through the
  right-click menu. The lists can be opened in their own resizable window.
- **PSTH > Groups** shows all groups (heatmap rows grouped by color, one mean
  +/- SEM per group with n in the legend), a single group, or every recording
  pooled. Metric and global points are tinted by group.
- Groups only change which rows are shown together. Trial matrices, events and
  statistics definitions are unchanged. Group CSV exports and project files
  record the attribution.

## Editable figure and vector export

- Results plots sit in one seamless figure with invisible draggable dividers,
  including a heatmap/PSTH ratio handle that keeps the time axes aligned.
- Right-click a plot to remove it, switch it to another analysis, or restore it.
- PDF and SVG exports are rebuilt with matplotlib: one path per curve and real,
  editable text. Heatmaps remain images.
- Heatmap color controls moved to a right-click menu on the color bar (limits,
  contrast mode, auto scale, exact limits, palette, histogram editor). Settings,
  projects and exports are unchanged.

## Recording and behavior lists

- **+** adds files (appended, several at once), **x** removes the selection,
  and a per-row **x** removes one row. Files on disk are never touched.
- Drag rows by their six-dot grip to reorder. The right-click menu adds move
  up/down/top/bottom, auto match by name, open containing folder and group
  attribution. Both lists keep identical row heights and scroll together.
- New behavior files pair with the first recording line that has no behavior.
  pyBer only asks which recording to use when every line already has one.
  Multi-animal tables ask only for the animal. Reordering re-pairs by line and
  recomputes the PSTH; **Pair with recording** pins a pairing explicitly.
- Rows that are not paired line by line are flagged. The behaviors list shows
  the behavior file names.
- Fix: the line-wise fallback no longer reuses a behavior file already named
  after another recording.

## Shorter settings panels

PSTH, Events and Spatial settings are split into subsections listed on a narrow
vertical rail with rotated labels. Only the selected subsection is shown, so
the panels no longer need long scrolling, and each panel remembers the last
subsection used. Form rows wrap instead of being clipped in narrow drawers.

- PSTH: Alignment, Window, Groups, Behavior, Filters, Inclusion, Metrics, Global.
- Events: Source, Detection, Baseline, Output.
- Spatial: Trajectory, Occupancy, Range, Time, Activity.

## Compatibility

No analysis formula changed in this release. Projects and parameter files from
0.56 load unchanged. See the
[groups and figure export guide](../groups_and_figure_export.md).
