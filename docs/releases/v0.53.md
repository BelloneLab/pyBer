# pyBer 0.53

Behavior and zone analysis in the existing pyBer workspace.

## Downloads

- **Windows GUI:** `pyBer-windows.exe`, with its runtime bundled inside.
- **Windows CLI:** `pyBer-cli-windows.exe`; `--version` reports `pyBer 0.53.0`.
- **Checksums:** `SHA256SUMS.txt` contains SHA-256 hashes for both executables.

## Improvements

- Zone / Behavior selection extends the existing postprocessing dashboard. Zone keeps its familiar pre/post PSTH workflow.
- Automatic detection of MAMIR wide-frame, long-frame, bout and zone exports, plus EthoVision arena workbooks. Select the scored animal, arena and matching fiber recording explicitly.
- Searchable behavior choices with whole-row click targets, automatic updates and filtered bulk selection.
- Before/during/after comparisons use complete bouts. Individual mode uses one recording; Group averages recording means with equal weight and reports contributor counts and SEM.
- Behavior events also use the existing onset/offset/transition alignment, PSTH filters, normalization and group trial/animal displays.
- Clearer heatmap timing and units, visible PSTH controls, resizable panels, comparison legends outside the data area, and readable summary annotations in compact plots and exports.
- Comparison settings and source pairings survive project saves; Recent Files uses the same format detection as the main loader.
- Fixed View-menu submenu lifetime on affected PySide6 versions.

## Compatibility and analysis notes

Original source files are never rewritten by these imports. Existing generic
behavior tables and legacy Zone calculations remain supported.

The PSTH baseline calculation is unchanged: normalization is performed per event
using the configured baseline window. It does not automatically exclude other
bouts, and an end of zero includes the alignment-time sample when present.
Baseline suitability remains an experimental choice. The separate
before/during/after comparison uses processed signal units and does not inherit
PSTH normalization or event filters. Its comparison-only offset does not shift
the heatmap. Repeated sessions are not automatically grouped by mouse identity.

Users of the unreleased development MAMIR frame importer should re-import their
original frame files: a column-order error could associate flags with the wrong
behavior names. This release explicitly matches columns by name and warns about
older embedded imports without silently modifying saved data.

The optional example script labels simulated fiber signals explicitly; its
outputs are software demonstrations, not experimental results. Windows is the
packaged release platform. FLMM still requires external R/fastFMM.

See the [behavior and zone guide](../behavior_import.md) for formats, timing,
group weighting and synchronization requirements.
