# pyBer 0.50

This release improves interactive postprocessing, Windows file handling and application branding.

## Downloads

- **Windows GUI:** download `pyBer-windows.zip`, extract the complete folder, then run `pyBer/pyBer.exe`. Keep `_internal` beside the executable. Extract into a new folder when upgrading.
- **Windows CLI:** download `pyBer-cli-windows.exe`. Run `--version` to confirm `pyBer 0.50.0`.
- **Checksums:** `SHA256SUMS.txt` contains SHA-256 hashes for both downloads.

## Highlights

- Signal-event detection previews update automatically after settings changes. Automatic thresholds can be used as a starting point for manual adjustment.
- Gap-aware peak detection, rolling-baseline noise estimation, shaded noise bands, threshold guides and compact peak markers.
- Per-file batch detection retains zero-peak and failed-file summaries. Rate estimates use observed duration, and intervals stay within recordings and continuous segments.
- Newly loaded traces fit their preview axes; preprocessing cuts remain visible as gaps in postprocessing.
- PSTH normalization changes reset incompatible heatmap limits. The new **Auto scale** action restores full-range, robust or symmetric contrast without modifying numeric data.
- Numeric fields support normal keyboard editing and text selection, with fourteen synchronized sliders. Small solver tolerances retain their intended precision.
- Compact file/status presentation, matching undo/redo icons, and more room for figures.
- Windows file and folder drops work directly on lists and load buttons, including detached drawers. Explorer drops import without moving source files.
- The original mouse-and-optics logo is redrawn as SVG. The taskbar icon is frameless, with explicit Windows shell branding and persistent icon resources.

## Analysis compatibility

Peak detection and derived event metrics can differ from v0.49, especially around gaps, recording edges and drifting baselines. Full-window AUC is unavailable when its window crosses missing data. Noise estimation remains per recording, so abrupt changes in noise can still affect detection sensitivity. Review thresholds against your recordings.

Heatmap autoscaling and trace gap separators affect display only. Raw recordings and metadata are not modified by these changes.

The FLMM path still requires an external R/fastFMM installation. These Windows packages do not bundle a complete R installation.
