# pyBer 0.58.1

Choose **PSTH → Alignment → Align to → Event marker** to align recordings to their saved marker times. This works with photometry alone. The PSTH/heatmap event picker also offers the marker alongside scored behaviors.

When you open a v0.58 project, its saved injection times appear under **Injection**. Each recording keeps its time and clock, including zero and **None**. Renaming the marker changes the label across the analysis. With scored behaviors, choose **Before** or **After** the named marker in the PSTH settings.

In **Recordings**, the **Input signal** column shows the active output for each preprocessed file. If the file contains both dFF and z-score, select either one. To display those values directly in a PSTH, set its normalization to **Original processed units**. Projects retain the selection and stored alternatives.

In the PSTH window settings, choose seconds, minutes or hours for the pre/post window, baseline and metrics. **Use available recording time** fits the window around the selected events. For a 40-minute recording with a marker at minute 10, this gives 10 minutes before and 30 after. The bin count updates with the resampling rate.

Group PSTHs use a shared relative time axis. Move over the mean plot to see how many recordings contribute at each time. Average PSTH CSV and HDF5 exports include this count as `n_recordings`. Shorter recordings and gaps contribute only where samples are available.

Download **pyBer-windows.exe** for the desktop app or **pyBer-cli-windows.exe** for the command-line tools. **SHA256SUMS.txt** contains checksums for both executables.
