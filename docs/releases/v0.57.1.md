# pyBer 0.57.1

Bug-fix release: parameter values are visible again, and every numeric setting
has a slider.

## Downloads

- **Windows GUI:** `pyBer-windows.exe`, with its runtime bundled inside.
- **Windows CLI:** `pyBer-cli-windows.exe`; `--version` reports `pyBer 0.57.1`.
- **Checksums:** `SHA256SUMS.txt` contains SHA-256 hashes for both executables.

## Fixed

- **Invisible values in numeric fields.** The v0.57 Windows build bundled
  Qt 6.11.3, which squeezes the text area of styled numeric fields to 1 pixel.
  Every value (artifact thresholds, windows, baselines, filters...) looked
  empty although it was stored and used. The build is now pinned to Qt 6.11.2,
  and pyBer also repairs the field layout itself if a future Qt version
  repeats the problem.
- **Behavior drawer overflow.** The three Behavior footer buttons forced the
  drawer wider than the screen, so its content was shifted and clipped. The
  buttons now stack when there is not enough room.

## Improved

- **A slider next to every single-value numeric setting**, in the
  preprocessing and postprocessing drawers and in dialogs. Drag the slider to
  explore, or type an exact value in the field (Enter or Tab applies it). Wide
  ranges use a logarithmic slider so small values stay reachable. Paired
  fields (Start/End, Pre/Post) keep their typed fields only.

## Compatibility

No analysis formula changed. Settings, projects and exports from 0.57 load
unchanged; the sliders write through the same fields, with the same ranges and
validation.

Full changes: https://github.com/BelloneLab/pyBer/compare/v0.57...v0.57.1
