# pyBer 0.55

Select the correct animal from multi-ID behavior and zone tables without changing source data.

## Downloads

- **Windows GUI:** `pyBer-windows.exe`, with its runtime bundled inside.
- **Windows CLI:** `pyBer-cli-windows.exe`; `--version` reports `pyBer 0.55.0`.
- **Checksums:** `SHA256SUMS.txt` contains SHA-256 hashes for both executables.

## Fixes and improvements

- Flat CSVs with several animals per video frame now prompt for the animal/arena ID before interpreting repeated timestamps. Choices include mouse and condition labels where available, and distinguish separate streams with reused IDs.
- Supports two, four, or more IDs in both the Behavior/Zone add workflow and the existing Setup importer. Existing workbook sheet/arena selection remains available.
- Explicitly pairs the selected animal with its processed fiber recording. The selected source is not implicitly reused for other recordings in Group view.
- Project saves retain the selected identity and pairing. Cancelling selection leaves existing imports intact.
- Missing or repeated times within the selected animal are still rejected rather than silently repaired. Invalid older embedded timelines are reported in the comparison panel with instructions to re-import.
- Identity and frame metadata are excluded from automatic behavior choices.

## Using an existing multi-animal export

1. Load the processed fiber recording(s).
2. Add the behavior CSV and choose the animal/arena ID.
3. Select its corresponding fiber recording when prompted.
4. Add the same CSV again if another animal needs to be paired with another fiber recording.

If an older project contains the unsplit table, remove that behavior entry and
re-import the original CSV. Removing an entry does not delete its source file.
Video trial numbers and fiber acquisition numbers need not match; confirm the
animal, session and synchronization rather than pairing by number alone.

## Data and analysis compatibility

Selection filters rows in memory only. It does not rewrite source files, shift
timestamps, sort observations, deduplicate different animals together, or fill
missing values. PSTH baseline normalization, event calculations, signal processing,
group averaging and heatmap color controls are unchanged.

Validation includes multi-ID selection, four-ID imports, cancellation, project
round-trips, explicit group pairing, legacy imports and arena-sheet selection.
Read-only checks on 28 real two-animal CSVs verified all 56 selected timelines,
and the matching fiber recording produced a PSTH and comparison without the
previous error. Source-file hashes remained unchanged.

See the [multi-animal import guide](../behavior_import.md#flat-csvs-with-multiple-animals-or-arenas).
