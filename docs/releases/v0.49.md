# pyBer 0.49

This release refreshes the analysis workspace and corrects postprocessing and export inconsistencies.

## Downloads

- **Windows GUI:** download `pyBer-windows.zip`, extract the complete folder, then run `pyBer/pyBer.exe`. Keep the `_internal` folder beside the executable.
- **Windows CLI:** download `pyBer-cli-windows.exe`. Check the version with `--version`.

## Highlights

- Clean, data-aware empty workspaces. Plots and their controls appear when data is available; clearing recordings removes old results.
- Consistent white vector tool icons, understated panel headings without circular initial badges, and more reliable Windows taskbar branding at high display scaling.
- Midnight, Paper, and Sand plot themes, resizable plot cards, focused layouts, and adjustable heatmap contrast.
- Onset and offset exports have distinguishable names. Repeated export bundles preserve previous files, and individual exports use the selected recording.
- More consistent HDF5/CSV export coverage, export manifests, and publication figures in PNG, PDF, and SVG.
- Corrected missing-data handling, event grouping/filtering, uncertainty estimates, exact-window AUC, exclusion handling, and stale-result clearing.

## Analysis compatibility

Numerical corrections can change results near missing samples and recording boundaries. Baseline z-scores reject flat or insufficient baselines. Mean and SEM use finite contributing rows; incomplete AUC windows remain unavailable.

Pre/post comparisons use an exact paired sign test. Trial-level inference within a recording remains exploratory; pooled trials across animals do not receive inferential p-values. Publication p-values are unadjusted across behaviors. See the user guide for assumptions and conventions.

The FLMM path still requires a working external R/fastFMM setup. These Windows packages do not bundle a complete R installation.
