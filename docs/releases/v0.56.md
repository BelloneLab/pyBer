# pyBer 0.56

Combine selected behaviors or zones into one named event.

## Downloads

- **Windows GUI:** `pyBer-windows.exe`, with its runtime bundled inside.
- **Windows CLI:** `pyBer-cli-windows.exe`; `--version` reports `pyBer 0.56.0`.
- **Checksums:** `SHA256SUMS.txt` contains SHA-256 hashes for both executables.

## How to use

Click **Combine…** beside the PSTH behavior/zone selector, or in the Behavior
comparison controls. Select two or more labels, enter a name such as "Zone 1 or
Zone 2", and create it. The combined label is selected automatically; original
labels remain available.

## Combination rules

- Uses OR: active when any selected behavior or zone is active. This is not an AND rule and does not sum signals.
- Overlapping or touching bouts merge into one bout without double counting. A direct transition between selected zones remains inside their union.
- Known activity takes precedence over a missing state. Otherwise, missing observations remain unknown rather than being filled with zero.
- Event-list intervals are merged; duplicate point events count once. Combining sampled state columns with event-list labels is rejected because their missing-observation semantics differ.
- Each source is combined independently. A source missing a required label is excluded and reported; animals are never pooled into one event timeline.

## Compatibility and preservation

Combined labels use the existing Individual/Group analysis, PSTH filters,
baseline normalization and Zone pre/post calculations. Behavior combinations
also work in the before/during/after comparison. Source CSVs and original label
arrays are unchanged.

Projects preserve combined values and definitions. Comparison exports and PSTH
parameter files record the OR definitions. Derived labels are rebuilt after
source/arena changes and become unavailable if required inputs are missing.
After loading additional sources, create the same name with the same inputs to
extend the combination to those sources.

Validation covers OR truth tables with missing values, overlapping/touching bouts,
timestamp events, source preservation, Individual/Group trial and recording rows,
project round-trips, and real-data combined-zone analysis.
