# pyBer 0.60

**Named metric windows.** Double-click the **Pre** or **Post** window label under **PSTH → Metrics** to rename it. **+ Add window** adds further response windows, for example Early and Late for a bimodal response, each with its own name, start and end. There is no limit to their number. Every extra window is shaded on the mean PSTH.

**Comparing the windows.** With an extra window, **Compare windows** chooses what the metric panels show. **All windows together** (default) gives one panel per metric with every window side by side and each trial joined by a line. It reports a Friedman test across the windows and an exact paired sign test for every pair (Pre vs Post, Pre vs Late, Post vs Late), Holm-corrected across pairs and metrics. **Each window with Pre** gives one panel per window. Points, bars and box plots are available in both. Exports add `*_windows.csv`, `*_window_pairs.csv` and `*_window_rows.csv`.

**Windows across groups.** In Group scope, two group comparisons show every window. **Pre and Post side by side** draws Pre, Post and Late for each group, one line per animal, with a paired test for each pair of windows within a group. **Groups overlaid** puts the groups on shared window ticks: a mean ± SEM line per group, the animals as thin lines, a colored legend, and the group × window interaction (mixed ANOVA, Greenhouse-Geisser corrected beyond two windows). Groups with fewer than 3 animals are drawn, not tested.

**Individual traces.** The mean PSTH can show the average, every trial (every animal in Group scope) or both, from **Hide/show traces** or the right-click menu. Traces can be shaded by trial order or by response amplitude, with adjustable opacity and line style. Pointing at a trace highlights and names it. The SEM band is outlined, and the SEM bands of the group PSTH, which were not drawn, are now visible.

**Several behaviors side by side.** Check two or more behaviors in the Events panel to get one column per behavior: heatmap, mean PSTH and metric, on a shared color scale and y range. Columns wrap onto further rows instead of shrinking, and the trace preview draws each behavior's events in its color.

**State-space (PCA) panels.** **Change to → State-space (PCA)** replaces any panel with the trajectory of the event-aligned response. Right-click options choose the behaviors, the groups, the method (delay embedding of each mean response, or recordings as dimensions), the delay window and the component pair. Further panels show the event-aligned component scores, group-specific weights, a PCA fitted per recording and trial response clusters. These views are descriptive.

**Event-scale normalization.** The prominence-normalized output now draws what sets its scale on the output plot: the baseline region, the top events used for the scale and the other detected events. Event size can be the peak prominence or the spontaneous-event amplitude, with a preset following Pascoli et al. 2026. Event files (EthoVision exports, state tables, onset tables, time lists) define windows to exclude or to use exclusively. Thresholds are entered in dF/F or in multiples of baseline noise, and a live summary reports the event count, rate and scale. Outputs with the previous settings are unchanged.

**Events.** The event list of a behavior has an **Export** button that writes the listed events (recording, behavior, onset, offset, duration, status) to a CSV file.

**Saved z-scores.** Postprocessing uses the whole-recording z-score stored in processed CSV files and older projects.

**Display.** Metric panels are no longer cut off when several are shown: the panel grid uses the columns that fit, long titles shrink to the panel, and the results area scrolls instead of squeezing the panels. Window panels no longer have a dark frame on light plot themes.

Download **pyBer-windows.exe** for the desktop app or **pyBer-cli-windows.exe** for the command-line tools. **SHA256SUMS.txt** contains checksums for both executables.
