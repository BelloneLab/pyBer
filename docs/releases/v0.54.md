# pyBer 0.54

Direct, display-only heatmap color adjustment in the existing analysis workspace.

## Downloads

- **Windows GUI:** `pyBer-windows.exe`, with its runtime bundled inside.
- **Windows CLI:** `pyBer-cli-windows.exe`; `--version` reports `pyBer 0.54.0`.
- **Checksums:** `SHA256SUMS.txt` contains SHA-256 hashes for both executables.

## Improvements

- Color controls above the PSTH heatmap work in Zone and Behavior, for both Individual and Group views.
- Drag color-bar handles directly, or select **Adjust** for spatial-style histogram cursors, exact **Min / Max** inputs and palette selection.
- **Auto** restores the selected full-range, robust (2–98%) or symmetric-about-zero contrast mode.
- A blue–white–red palette complements the existing sequential palettes. Pair it with symmetric limits to place zero at the midpoint.
- Fixed limits and palette choices survive project saves and match publication figures. Interactive editor controls are omitted from plot-image exports.
- PSTH color limits no longer carry over to spatial maps with different units.
- Opening the editor preserves the plots' available height; **Show heatmap** includes the color controls.

## Compatibility and analysis notes

These changes affect display only. PSTH baseline normalization, event selection,
filtering, signal values, group averaging and statistics are unchanged. Original
source files are not rewritten. Existing generic behavior imports, Zone analysis
and saved projects remain supported.

Robust contrast saturates colors outside its percentile limits; it does not clip
or remove signal data. Fixed limits persist across behaviors and recordings and
reset when normalization changes. For comparable colors across animals or groups,
use identical fixed limits and units. Automatic scaling is local to each displayed
matrix and should not be interpreted as a shared amplitude scale.

No new baseline is introduced. The configured PSTH baseline is still a signal
reference, not a guarantee of a behavior-free interval.

The optional `--heatmap-colors` example uses explicitly simulated fiber data and
isolated preferences. Windows remains the packaged release platform.

See the [behavior and zone guide](../behavior_import.md#adjusting-heatmap-colors)
for usage and interpretation.
